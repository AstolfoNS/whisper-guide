# 测试与验收

当前检查命令统一维护于本文，开发环境见[开发指南](development.md)。测试覆盖与实际设备验收分开，不把ready、数字静音或模拟服务当作中文准确率。

## 自动化检查

后端：

```bash
cd backend-core
uv run ruff check .
uv run ruff format --check .
uv run pytest
```

前端：

```bash
cd frontend
pnpm test
pnpm typecheck
pnpm build
```

Chromium集成：

```bash
cd frontend
# 仅首次需要，已安装时跳过
pnpm exec playwright install --with-deps chromium
pnpm test:e2e
```

浏览器测试使用8010/5174独立服务、临时数据库、合成麦克风、模拟ASR和内存音频，不调用真实付费模型、不操作8080服务。截图在frontend/test-results/screenshots，失败trace/report位于忽略的测试产物目录。文档截图仅保留明确引用的当前示例，不在每次测试时重写。

## 覆盖范围

| 范围 | 关键验证 |
|---|---|
| 讲稿与配置 | 批量上传原子性、编码/大小、草稿/激活、修订冲突、凭据不回显 |
| 五状态与游标 | 暂停/打断/结束优先级、分段/全文边界、回读、迟到回包隔离 |
| 音频与识别 | 去直流/声学门控、底噪学习撤权、轻声、迟到final、时钟与回退 |
| 自动恢复 | 600单位外跳读/回读、独立连续证据、重复段消歧、撤回和重建流 |
| 实时与LLM | 临时位置不提交、partial结算、模型追赶、有依据纠错、旧结果不放行新声音 |
| 前端与浏览器 | 键盘交互、路由资源释放、实际播放确认、配置发现、完整自动提示闭环 |

## 设备与部署验收

自动化不替代目标麦克风、耳机、读屏、弱声/远讲、键盘/风扇/音乐、背景讲话、回声和长时会话。记录误失锁、错误跳转、充分正文后的恢复率、恢复延迟与实际识别源。

真实云端需分别验证鉴权/协议、中文识别与模型生成权限；静音空音频响应只证明网络/协议。TTS依赖后端网络，浏览器播放需输出设备与授权。

部署验证另执行Compose配置、镜像构建与健康检查，步骤见[部署手册](../DEPLOY.md)。源码测试或清理不表示运行容器已经更新。

# 连续朗读后识别混乱排查（2026-10-24）

## 当前判断

用户现象为开始能正常识别，之后不定时失准，未确认固定句子、时间点或与提示播放的关系。未采集用户麦克风音频，不能据代码审计断言其现场每一次失准都来自同一原因。

只读检查当前生效方案为 doubao revision 14：STT 使用 cloud / volcengine-ws / ASR 2.0 小时制；文本语义对齐为 off。本次未修改方案、凭据、麦克风设置或运行中的容器。因此本次现象不应归因为方舟文本模型正在改写结果；应先区分原始 ASR、讲稿匹配和云端回退三个层次。

## 确认的路径与缺陷

### 非语音结果也可以影响定位

当前 VAD 用于计时、人声打断与云端结果超时，不是完整的声学降噪/音频门控。VAD 为 false 的 PCM 仍原样送入 STT；云端非填充词文本会被视为漏检人声的证据，并可启动 speech_start，final 进入本地 ScriptAligner。

离线替身复现：先可靠对齐“大家好”，再输入全零 PCM、VAD=false，并模拟云端 final“火星飞船发射”，会收到这段原始文本，位置转为不可靠、自动提示停用。这证明接收侧缺少独立声学证据约束；不是证明真实豆包一定会从数字静音生成该句。原始错误结果与脚本位置失配必须分开判断。

不能简单停发静音，也不能仅因当前帧 VAD=false 就丢弃迟到 final：流式 ASR 需要尾部静音定稿，低音量人声也可能被 VAD 漏检。完整的抗噪升级应使用有界预卷、尾部保持、背景噪声估计及分段人声证据，并验证弱语音不被切掉；本轮没有未经麦克风验收就启用激进门控，也没有宣称解决所有杂音转写。

### 长句被误罚为远距离跳转

旧 ScriptAligner 把候选句末到当前游标的距离直接用于邻近分和远跳惩罚。同一句从当前位置开始正常读，越长的识别片段，句末自然越远，却被当作跳转。离线检查可复现：36 个内容单位的完全正确原文仍无法匹配，32 个单位已接近阈值。云端分段长度变化时，用户可能在后续长句突然看到“无法可靠定位”。这属于本地对齐错误，并非证明 ASR 原始文字已错误。

### 发送耗时累积与回退

旧 WebSocket 发送循环每块发送结束后再等待 200 ms。音频块本身是 200 ms，网络发送耗时因此不断叠加到节拍，持续采集时可能慢慢填满有界缓冲。到达上限会保护性回退本地，不会无限占用内存；如果未注意“识别已回退本地”来源提示，可能感到模型在使用途中突然变差。

真实链路何时积压仍取决于网络和主机调度。本次使用可控慢发送时钟验证算法，不把模拟故障当作用户网络现场证据。

## 设备与使用边界

前端已请求 echoCancellation、noiseSuppression 和 autoGainControl。请求约束不等于所有设备都按相同方式实现；自动增益可能改变底噪可闻程度，尚未验证用户设备，不直接认定其为根因。

PROMPTING 时前端会停用采集与麦克风轨道、清理 worklet 残帧；重新识别会建立新轮次。未发现自身 TTS 整段必然录回的代码证据。外放和房间残余回声仍需在耳机与目标麦克风上比较验证。

人工排查时，分别观察“实时识别”和“讲稿匹配”：原始文字错而匹配正确属于已校准；原始文字正确而匹配失败属于定位问题；显示“识别已回退本地”意味着实际识别源已切换。可用耳机、相对安静环境和固定麦克风距离对照，但这些操作不替代代码修复或真实准确率验收。


## 本轮修复与验证

- `app/domain/tracking.py`：使用候选完整范围相对游标计算距离，连续长句不按句末距离受罚。模糊比较仍只使用末 64 单位；超过 64 的段必须先验证附近省略前缀的原文证据，最大 256 单位。较长段若前缀本身识别错误，仍可能保守不匹配，不承诺无限长或任意错误都可纠正。
- `app/infrastructure/speech_websocket.py`：将发送计时基准放在 socket.send 前，200 ms 周期包含发送耗时，空闲后从实际发送时刻重新计时，不突发补发。真正慢于音频实时速率的链路仍受一秒缓冲与发送超时保护。
- 新增 `test_long_script_alignment.py` 12 项，覆盖 36/85/256 单位原文、已读后顺延、近处重复和远处重复拒绝、无关文字拒绝、英文数字单位、局部回读、伪前缀和超限保护。原始实现先复现 5 项失败，再修复。
- 新增 `test_stream_pacing.py` 5 项，使用确定性时钟模拟 20/80 ms 发送耗时，30 块发送起点跨度均为 5.8 秒，峰值缓存不超过 7040 B；同时验证空闲恢复不突发、300 ms 慢链路仍有界回退、单次卡住仍超时。旧代码先复现 3 项失败。

# 模型配置指南

在 `/settings/models` 管理方案。工作台操作见[使用指南](user-guide.md)，完整字段和网关契约见[Provider 接口](speech-provider-interface.md)，服务部署和私有配置备份分别见[部署指南](../DEPLOY.md)与[维护手册](maintenance.md)。

## 先区分三条链路

| 能力 | 作用与发送内容 | 配置方式 |
|---|---|---|
| 语音识别 STT | 把麦克风音频转成文字；本地识别或授权后发往云端 | 方案中的 STT Provider、协议、地址及独立语音凭据 |
| 文本 LLM | 用讲稿片段和识别文字辅助本地定位，不接收录音 | 独立的对齐模式、Base URL、模型 ID、文本 API Key 和超时 |
| 提示合成 TTS | 把待提示的讲稿文字合成为音频 | 当前使用需要服务器联网的 edge-tts，不由 STT/LLM 方案切换 |

云端 STT 与文本 LLM 可以分别启用。开启 LLM 不会把本地 STT 改成云端；填写方舟文本 API Key 也不会自动配置火山语音。没有 LLM 时，系统仍可本地对齐并从全稿自动恢复定位。

## 环境变量与方案优先级

.env中的STT/LLM字段是初始方案的引导值，不会在每次重启时覆盖用户方案。首次没有私有仓储时，“现有配置”使用环境默认；已有WHISPER_GUIDE_DATA_DIR/.model-configs.json时，以文件中的独立生效快照为准。保存草稿不等于激活，重新创建容器也不激活未发布草稿。

非模型启动参数，例如项目标题、静音默认、上传限制和TTS声音，不属于该方案快照。修改这些环境值并重新创建后端容器后生效；刷新页面可读取标题、静音和上传公开默认，TTS声音由后端用于后续合成。已恢复的会话保留自己的静音参数。完整变量表与入口位置见[开发指南](development.md#环境变量与生效顺序)。

STT_PROVIDER_CONFIGS是仍受支持的服务器注册表，与方案中的Provider选择不同；注册表本身不写入方案。条目中的access_token_env读取容器内/后端进程环境，根.env中任意新增同名键不会自动传入容器。不要把空密钥、当前关闭的云端能力或仅作填表元数据的预设误判为“变量无效”。

## 创建、保存与激活

1. 点击“新建配置”，或选中已有方案后“复制”。复制会建立独立方案，只复制非敏感参数，所需密钥需重新填写。
2. 输入名称、说明和识别／语义设置。可以在保存前分别测试 STT 与 LLM。
3. 点击“保存修改”。保存只更新方案草稿，不改变实际生效版本。
4. 结束所有未终止会话，点击“设为生效配置”。下一次创建的会话使用激活的版本。

“当前生效”与“修改待激活”可以同时出现：该方案正在生效，但新修改尚未替换独立的生效快照。重启也不会让未激活的修改自动生效。概览和诊断区展示实际生效配置；会话记录创建时使用的配置版本。

演讲期间允许编辑、保存及测试其他方案，但任何未终止会话都会阻止激活，包括就绪、暂停和断线会话。暂停不等于结束；若激活返回 `409 SESSION_ACTIVE`，请回工作台结束演讲，并检查“有可恢复的会话”列表。其他页面仍连接的会话应在所属工作台结束。

内置“默认本地离线模式”不可编辑或删除，可复制后修改；名称中的“本地”指识别方式，提示合成仍需联网。当前生效方案也不能删除。其余方案可在确认后删除，最多保存 50 套方案。

离开或切换方案时，未保存修改会提示确认。出现“修订冲突”说明其他页面已修改相同方案；刷新并比较内容后重新编辑，不要用旧修订号强行覆盖。

## 密钥如何保存和复用

| 密钥框操作 | 含义 |
|---|---|
| 已有方案留空 | 保留后端已存凭据；测试和模型发现也可复用 |
| 输入新值 | 当前表单测试使用新值，保存后替换后端凭据 |
| 点击清除凭据 | 明确请求删除；保存后生效 |
| 显示 `****` | 只表示已配置，不是真实密钥，不应复制回密码框 |
| 新建或复制 | 不继承其他方案的秘密，需要自行填写 |

文本密钥与语音凭据分别清除。文本密钥的“清除”标记还会让本次模型发现不再复用已存密钥，即使尚未保存。

密钥只保存在后端私有配置中；页面不返回明文，也不把输入密码持久化到浏览器存储。列表请求会把文本 API Key 发送至当前 Base URL，所以修改地址或服务商前，应核对目标服务，并替换不属于该服务的旧凭据。

当前方案和独立生效快照保存在 `WHISPER_GUIDE_DATA_DIR/.model-configs.json`，容器默认对应宿主 `data/sqlite/.model-configs.json`，文件权限为 `0600`。旧 `.model-settings.json` 会迁移为“现有配置”；新仓储存在后以其生效快照为准。两种文件都可能包含凭据，备份和迁移按维护手册处理，不放进 Git、日志或发布包。

## 配置语音识别

### 本地 STT

选择“本地 sherpa-onnx”，不需要云端音频授权或云端语音密钥。“检查本地 STT”会尝试加载识别流，只确认本地能力，不验证麦克风、实际中文准确率或 TTS 网络。

现行本地模型保留INT8 encoder/joiner以控制体积，使用FP32 decoder修复叠字；已有旧模型目录先运行开发指南中的模型更新脚本，再重建镜像。原始识别保留真实重复，不用讲稿匹配结果或盲目去重冒充ASR准确率。

本地资源不可用时，按[维护手册](maintenance.md)检查模型文件与服务端依赖。云端方案的本地回退同样依赖这些资源。

### 通用 HTTP JSON 网关

选择云端 STT 和 `http-json`，填写符合本项目网关契约的 Endpoint、独立 Access Token，按需要填写 App ID，并明确勾选音频发送授权。

公网 Endpoint 需要 `https://`；仅本机环回调试允许 `http://`。这是接收 PCM16 JSON 请求、返回识别文字的语音网关，不能直接填写聊天模型的 Base URL，也不能假定任何厂商原生 REST 接口都兼容。请求和响应格式见[Provider 接口](speech-provider-interface.md)。

### 火山语音 WebSocket

选择云端 STT 和“火山语音 WebSocket”，可点击“填入推荐设置”。以下是项目内置填表值，实际地址与资源必须以账户已开通服务为准：

| 字段 | 填写方式 |
|---|---|
| Endpoint | `wss://openspeech.bytedance.com/api/v3/sauc/bigmodel_async` |
| Resource ID | 内置 `volc.seedasr.sauc.duration`；也可填写已开通的兼容资源 |
| 鉴权模式 `api-key` | 填独立的语音服务 API Key，无需 App ID |
| 鉴权模式 `app-token` | 填语音 App ID 与 Access Token |
| 语音请求超时 | 默认 `5000 ms`，范围 `200–30000 ms`，必须为整数 |
| 二遍复核 `enable_nonstream` | 仅 `bigmodel_async` 使用；其他端点忽略 |

公网需要 WSS，只有环回调试允许 WS。语音 Endpoint 不能包含用户名、密码、查询参数或 URL 片段，凭据必须填入独立字段。文本模型 Key、API Key 的资源编号和语音 Resource ID 不能互相替代。

云端识别故障、超时或缓冲溢出时可回退本地。工作台显示实际来源及受控原因：连接/发送/结果等待超时、音频积压、HTTP状态或业务码，不回显地址与密钥。连接握手完成前不启用PCM，避免一秒传输缓冲被连接等待占满；只有经声学证据确认的人声启动结果等待期限，背景能量不会单独触发。云端测试不使用本地回退伪装成功。

## 配置文本语义校准

| 模式 | 行为 |
|---|---|
| `off` | 关闭文本模型，不影响本地定位与自动恢复 |
| `fallback` | 本地不能可靠定位且有充分有效文字时，异步请求辅助 |
| `hybrid` | 对符合证据条件的已结算片段异步校准，包括本地已匹配片段 |

需要辅助时可先选择 `fallback`，根据实际效果再决定是否使用 `hybrid`。短噪声不触发模型恢复；输出仍需讲稿原文与识别字面／拼音证据，并由本地规则验证。模型不能直接指定游标位置，也不能仅凭自报高置信度解除失配。

服务商预设为 `custom`、`deepseek`、`qwen`、`doubao`、`openai` 和 `ollama`，只帮助填写地址与示例模型名。预设不证明账号、配额或示例模型仍可用；选择“自定义”也不会改变调用协议。

接口必须兼容 Chat Completions：

| Base URL 形式 | 实际处理 |
|---|---|
| 主机根地址，如 `https://service.example` | 补 `/v1/chat/completions` |
| API 根路径，如 `https://service.example/v1` 或 `https://service.example/api/v3` | 保留路径，追加 `/chat/completions` |
| 完整 `.../chat/completions` | 直接使用 |

Base URL 只接受不带用户名、密码、查询参数或片段的 HTTP(S) 地址。填写模型名称时，使用服务商 API 调用示例或模型列表中的真实 `model` 值／接入点 ID，不要填产品展示名、猜测的别名或 API Key 资源 ID。

LLM 默认请求超时为 `1500 ms`，必须为正整数。错误、无效输出或超时会保留本地结果；本地仍未恢复时，继续朗读正文或手动定位。增大超时只延长允许等待，不会让模型响应更快，过慢结果也可能失效。当前没有单独的 thinking 参数开关。

三种时间参数互不替代：

| 参数 | 控制什么 |
|---|---|
| 工作台静音等待 | 停声后何时尝试自动提示；新会话取服务端环境默认（未改时3000 ms），最短1000 ms，可手动调整 |
| 云端语音超时 | 语音传输及等待识别结果；默认 5000 ms |
| 文本模型超时 | 一次文本辅助请求；默认 1500 ms |

模型请求在后台运行，不阻塞暂停、结束或本地识别。新 partial 不会反复取消已经发出的恢复请求；迟到结果仍需校验后续证据，不能覆盖人工定位或替新一轮待确认声音放行。详细恢复行为见[使用指南](user-guide.md)。

## 获取与选择模型列表

1. 在新建或已有方案中填写 Base URL 和文本 API Key；已有密钥可留空复用。
2. 点击“获取模型列表”。不要求先填写模型名称、配置名称或开启对齐模式。
3. 使用“筛选模型”查找，在“从模型列表选择”中选中 ID，或继续手动修改“模型名称”。
4. 开启 `fallback` 或 `hybrid`，点击“测试大模型连通性”，验证实际调用权限，再保存和激活。

列表请求只读取同一 API 根下的 `GET /models`，不调用生成模型，不保存或激活方案，也不自动翻页。服务不支持目录、目录为空、列表截断或没有目标模型时，都可手动填写 ID。目录中出现某个模型不证明当前密钥拥有它的生成权限。

请求时间不超过配置的文本超时与 30 秒上限中的较小值；响应大小最多 1 MiB，输出最多 500 个模型，过大的目录会失败或标记截断。列表查询不跟随重定向。

修改地址、密钥、清除标记、预设、切换方案或离开页面，会取消并清空旧列表；保存和测试也会停止目录查询，迟到的旧响应不会覆盖新来源结果。选择只修改当前草稿，仍需保存并激活。

## 看懂测试结果

测试使用当前表单，不保存、不激活，也不更改正在使用的会话。显式测试会发起相应请求，可能受服务商计费、限流或配额规则约束；顶栏的状态刷新不会调用付费模型。

| 测试 | 成功说明 | 尚未证明 |
|---|---|---|
| 检查本地 STT | 本地识别模型能够加载，`verified=capability` | 真实收音与识别准确率 |
| 测试云端 STT | 短静音请求的网络和响应协议可达，`verified=network` | 真实朗读效果与长时稳定性 |
| 测试文本 LLM | 短文本请求和响应结构可用，`verified=network` | 实际讲稿校准质量及稳定实时延迟 |
| 获取模型列表 | 当前目录请求成功 | 目标模型生成权限 |

火山语音测试会发送短静音和结束包并等待终止响应，初始 ACK 不算通过。已知空音频码 `45000002` 会明确标为“鉴权与协议可达，仍需工作台朗读验证”；其他业务错误仍失败。

测试接口的 HTTP 200 仅表示本地 API 正常返回，仍需查看结果中的 `ok`、`verified`、`error_code` 和耗时。STT 结果可能额外包含安全的 HTTP 状态或数字业务错误码；界面不显示上游原始正文或鉴权头。

## 错误分类与处理

| 错误类别 | 优先检查 |
|---|---|
| `CONFIG_INCOMPLETE` | 地址、模型 ID；语音还需凭据、Resource ID，旧鉴权还需 App ID |
| `CLOUD_OPT_IN_REQUIRED` | 明确勾选云端音频授权 |
| `TIMEOUT` | 对应的语音或文本超时、服务器网络、实际请求耗时 |
| `NETWORK_ERROR` | 服务器到外部服务的连接、DNS、代理及 HTTPS 证书 |
| `INVALID_RESPONSE` | 所选语音协议或 Chat Completions／目录响应是否兼容 |
| `HTTP_ERROR` | 对照下表检查地址、权限和配额 |
| `PROVIDER_ERROR` | 语音服务返回的业务错误码、独立语音凭据、资源开通与账户状态 |
| `RESPONSE_TOO_LARGE` | 模型目录超过大小限制，改为手动填写 ID |
| `UNKNOWN_ERROR` | 检查配置与服务运行环境，按维护手册排查 |

通用 HTTP 语音网关的失败可能仅显示受控的验证失败消息，不一定提供上述完整分类。

| HTTP 状态 | 建议检查 |
|---|---|
| 400 | 请求参数、模型名称与协议兼容性 |
| 401 | Key 是否有效、是否属于当前地址对应的服务 |
| 403 | 模型／语音资源是否开通、项目权限和账户状态 |
| 404 | Base URL、实际模型／接入点 ID，以及当前密钥访问权限 |
| 429 | 配额、余额与限流状态，稍后重试 |
| 5xx | 外部服务暂时异常，稍后重试 |

模型发现的 404／405 还可能表示服务不提供该目录接口，可手动填写模型 ID。404 不能单独证明某个模型对所有账号都不存在；请求很快失败也不能直接认定为超时。语音握手 HTTP 错误与建立连接后的业务错误是不同情况，应同时核对语音协议、资源和对应凭据。

方案管理另有 `409 SESSION_ACTIVE`、`409 REVISION_CONFLICT`、默认／生效方案受保护、参数校验失败等错误；配置存储不可写或损坏时可能返回 `503 PROFILE_STORE_UNAVAILABLE`。保留原文件，按[维护手册](maintenance.md)检查数据目录与配置，不要通过删除私有文件或重复更换密钥绕过问题。

所有预设、示例地址和一次测试结果都不构成模型可用性保证。最终应在工作台用目标设备真实朗读，检查原始识别、讲稿匹配、实际识别来源和提示播放；验证方法见[测试指南](testing.md)。

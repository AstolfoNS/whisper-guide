# 已知问题与现场验收边界

更新日期：2026-10-25。失锁自动恢复、平稳噪声门控与实时临时定位见[实现记录](auto-recovery-2026-10-25.md)。源码、运行镜像与设备验收分开记录。

## 噪声被过滤后自动提示仍暂缓

**状态：已补齐失锁后的持续全文重定位；无有效文字的待确认保护仍保留。**

保持监听，附近唯一正文可恢复；远处位置需要两个独立、连续且各不少于6内容单位的片段确认。重复句等后文消歧。出现“正在尝试自动恢复”“等待后续朗读确认”时继续清晰读正文，无需先手动定位；无法消歧时也可明确手动设定起点。

“已过滤”不证明本轮声音一定不是朗读。可信VAD人声却无有效转写时继续pending；真实短词失配仍触发AC-14，不能仅按文字长度恢复可靠。手动提示也不证明位置可靠。

## 临时位置与匹配评分

蓝色虚线是稳定partial的待确认位置；确认朗读与提示起点仍为独立标记。临时高亮不授权播报，不触发全文完成或移动确认游标。

recovery_status是对齐诊断，不是第六状态。searching等待正文，ambiguous等待消歧，confirming等待第二份独立证据。alignment_status仍为reliable/pending/mismatch；“上次匹配”不是当前ASR准确率。

## 抗噪与云端验收限制

600ms平稳VAD阴性窗口可收紧纯能量兜底，但强背景人声、音乐、突发杂音和回声仍可能被接收。当前不隔离主讲人，也没有新增神经降噪模型。

学习前的错误final可能短时影响位置。若对应声学证据随后被撤回，位置立即降为不可靠并保留历史偏移，继续等待正文；不猜测真正位置。长时间VAD漏检且能量平稳的弱声仍需设备验收。不要通过统一提高音量门限或放宽定位评分掩盖问题。

LLM可选，输出需文字/拼音依据和全文消歧；超时不阻断本地恢复，也不强制未知位置可靠。

用目标麦克风、耳机和固定距离对照轻声、远讲、回读、长停顿、回声与背景讲话。合成音频和模拟ASR不能替代设备与云端准确率验收。

/api/health及ready只表示能力/连接检查。本轮未重启8080服务；结束演讲后按[运维手册](operations.md)构建并切换新镜像。
